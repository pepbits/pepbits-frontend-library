# Consultation demo options

`form.json` supplies fictional clinician and visit-type options through the authenticated consultation API. Stable option IDs are persisted; labels use canonical localization keys. Clinician selection does not change the authenticated audit actor.

Notes persist in `RECORD_DATA_DIR/clinical-consultation.csv`. See the [user and integration guide](../../../docs/features/clinical-consultation.md) for contracts, preferences, recovery and production boundaries.
