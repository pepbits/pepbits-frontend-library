## Added and changed

`src/modules/teleconsult` ports Clinic Desk and CareCall as exactly two header modules. The existing SessionProvider → PreferenceHost → LocalizationProvider → ShellProvider chain and renderer registry remain intact. There are **154 menu destinations** across the healthcare app, including these nine. Three appointment record routes bring the Teleconsult route inventory to twelve.

| Header module | Sidebar destinations | Record routes |
| --- | --- | --- |
| Teleconsult Provider | `/teleconsult-provider`, `/schedule`, `/patients`, `/notes` relative to that prefix | `/teleconsult-provider/consult/:id` |
| Teleconsult Patient | `/teleconsult-patient`, `/register`, `/home`, `/book`, `/records` relative to that prefix | `/teleconsult-patient/visit/:id`, `/teleconsult-patient/visit/:id/summary` |

Header visibility follows authenticated role grants. Doctor/Nurse working modes, staff identity, beneficiary selection and effective branch settings come from the API session. The configured HTTP adapter supplies the original namespace and routing metadata; the optional same-origin proxy forwards Teleconsult role/patient and replay headers. The server independently validates tenant/branch scope, modes, ownership, recording consent, state, versions and idempotency.

Registration fields configure TemplateFields and patient worklists configure CollectionView with managed pagination. Public AsyncLookup, Source* controls, SourceDialog, shared overlays, ScreenHost notifications and printing are reused. Consultation, triage, schedules, note content, the patient phone and simulated media are product components (CMP-04). The shared shell owns viewport height; CareCall's bottom navigation stays inside its phone. Nested main landmarks, empty-list semantics, note heading levels and source palette contrast are corrected.

Scope changes abort/fence obsolete reads. Failed commands retain values; an unknown response outcome retains its replay key, including malformed successful JSON (now a structured 502). Version conflicts require explicit resolution. These are existing API persistence and transient editor semantics, not a new durable draft service. The quick-add listener respects effective shortcut settings and consumes its shortcut before the outer shell; SourceDialog owns focus/Escape behavior.

Host fonts, form/result scales, radius, table presentation/page size, formatting and motion govern applicable controls. CareCall keeps its source light palette with scoped contrast corrections. All 636 source literal message keys exist in each unchanged canonical English/Arabic/Hindi/Malayalam catalog; no local translation catalog is copied or backend fallback regenerated. Catalog presence and layout tests do not establish native-speaker approval.
