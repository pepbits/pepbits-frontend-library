## Added and changed

New private `@pepbits-demo/tenant-admin` (Next.js 16.3.3, React 19.2, Tailwind 4.1, port 3360), structured like the healthcare and ERP demos. The shared ApplicationProviders chain supplies the API session, API preferences and tenant policy through one serialized update path, the runtime catalog (`/localization?productId=nexora`) and the shell with the authenticated branch and role. AI is off.

| Destination | Route |
| --- | --- |
| Overview | `/` |
| Approvals inbox | `/approvals` |
| Activity log | `/activity` |
| 30 configuration pages from `GET /meta` | `/config/<resource>` |
| New record / open record deep links | `/config/<resource>?new=1`, `?open=<id>` (`?id=<id>` read too) |
| Preferences | `/preferences` |

The configuration pages are not listed in the frontend. A registry reader inside the authenticated host publishes `GET /meta` to the shell product, so the sidebar follows the server registry (canonical catalog keys label it where they exist) and is cleared on sign-out or another identity. One `tenant-admin` renderer in the public page-renderer registry serves every route; it stays mounted across Tenant Admin routes, so the module's scope-keyed store survives navigation. Unknown paths reach the module's not-found page.

The ported module keeps the source structure: one ResourceWorkspace list plus RecordDrawer draws all 30 pages from the registry field definitions; Overview, Approvals, Activity, the route tester and the command palette are the source components. Imports move to public Source* controls, shared Card/Table/Drawer/Modal, `@pepbits/icons` and `@pepbits/i18n/react`. The adapter maps module paths to `/reference-modules/tenant-admin/...` through the configured request with module/branch routing metadata only; the unchanged API derives the actor and its authority, independent approval and row versions. Idempotent writes, lost-outcome retry, field errors with preserved values, stale-version reload, scope disposal and the 20-second pending poll are retained.

Accessibility corrections found by Chromium and jsdom axe: the source combobox is named by its visible label (`aria-labelledby`); compact line-cell editors carry their column label; the toolbar Approvals link keeps its visible text first (label-in-name) with a screen-reader count; the Overview panel body is a focusable named scroll region; `overrides.css` darkens two source colour pairs below 4.5:1 (saffron ink on saffron-100; the `#A6B3B0` "not set" grey now follows the scoped muted ink). The module body is a `div` because the shell owns `main`. Module shortcuts listen in the capture phase so Ctrl/Cmd+K opens the module palette inside Tenant Admin pages; the shell palette stays available from its header button.
