## Merge into main — 23 October 2026

Branch `restructure/phase-6a` (`731b149`, built in a parallel worktree from `6c73e50`) was merged into `main` after phase 5 part 2 (`a5f49fb`) and phase 5b (`1401a36`). Corrections made during the merge:

- **Accessible-name change reaches the shell.** 6a changed `DropdownSelect`/`SearchSelect` to announce label plus selection (WCAG 2.5.3). The phase 5 part 2 header test looked for a button named exactly "Branch"; it now matches `/^Branch\b/` in `packages/shell/src/chrome-integration.test.tsx`. Behaviour is unchanged otherwise.
- **Chromium suite separated.** `packages/shell/src/sidebar-rtl.browser.test.ts` launches Chromium, which on this machine needs OS libraries that are not installed system-wide. Phase 5b ran it with a loader path. It is now excluded from `npm test` and runs with `npm run test:browser -w @pepbits/shell` (`vitest.browser.config.ts`); see the shell README.
- **Turborepo cache replay.** Earlier review reruns of `npm run ci` could replay cached task output from the implementing run when inputs were unchanged, so they were not always fresh executions. The root `ci` script now runs `turbo run typecheck test build --force`.
