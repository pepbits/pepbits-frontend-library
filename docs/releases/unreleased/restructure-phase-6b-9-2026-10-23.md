No duplicate generic lookup, notification, dialog lifecycle or form/table renderer is introduced. The app pins source `tailwind-merge` 3.7.0 instead of cloning class conflict resolution.

The unchanged backend owns trusted actor/branch/provider-resource assignment, transaction serialization, capacity/patient conflicts, durable replay, audit and simulated notifications. UI roles mirror the source but do not authorize commands. Host identities cannot be edited through source roster records.

Appointment/audit pagination follows host page size; daily calendars and bounded search/notification queues do not expose pagination. Facility wall-clock strings and native temporal machine values retain their meaning. Calendar positions and resource/status colors remain domain presentation. Source external fonts are replaced by the already bundled host fonts. Public-engine presentation and accessibility corrections intentionally change some source default geometry; exact source pixel parity is not claimed.

Recoverable failures preserve form values. Ambiguous identical command retries reuse their operation key; definitive refusals release it.
