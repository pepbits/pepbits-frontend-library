The existing provider chain and renderer structure are preserved: SessionProvider → PreferenceHost → LocalizationProvider → ShellProvider. Stable original page IDs and query semantics (`new`, `open`, `q`, `status`, `overdue`) are preserved. The registry snapshot is checked against the unchanged API. Creation, edits and action inputs configure TemplateFields; resource columns configure CollectionView. AsyncLookup and Source* controls from Pharmacy are reused. Notifications use ScreenHost. Product boards, dashboard charts, lifecycle maps, financial document geometry, line-value composition and palette orchestration remain demo components (CMP-04).

The API retains authorization, trusted actor identity, row versions, durable operation replay, transactional financial effects and independent decisions. Scope-keyed caches abort/discard obsolete reads and reset on host identity changes. Operational scope changes discard previous-filter list data. Recoverable failures retain editor input; ambiguous command failures retain the same replay key. No new durable-draft promise or frontend financial acceptance is introduced.

Host theme/font/scales/radius, table density/stripes/wrapping/sticky headers, page size, formatters, shortcuts and reduced motion govern presentation. Board requests retain the source API's bounded 300-row contract. Source CSS remains a frozen provenance baseline; shared-engine layout and effective host defaults replace exact legacy default pixel geometry. Canonical localization remains backend-owned. No source workflow calls for the available spreadsheet, form-designer, label-printing or physical-device patterns.
