Scheduling data comes from CareGrid's own unchanged Express + SQLite API through `src/adapters/caregrid.ts` (configured base URL, relative-path guard, structured failures carrying server alternatives, no credential forwarding). Sign-in, preferences, tenant policy and the runtime catalog come from the unchanged demo host API through the shared `ApplicationProviders` chain. One `CaregridLiveProvider` serves the header and page: reference metadata, notifications and the Server-Sent Events stream, whose events only trigger HTTP re-reads. Optional same-origin proxies stream events without compression. Workflows ported: four-step booking with urgent priority, courses and waitlist; schedule board with pointer and keyboard booking; appointment drawer (confirm, check-in, start, complete, no-show, undo, move, cancel with reason); front-desk flow board with waitlist and reminders; blocks with impact preview, reschedule-queue suggestions, keep-original and fix-all; facility holidays; resource week and weekly-hours editor; service rules; patient profiles; pharmacy queue and counter load; slot-length advice and utilization; help search; command-palette record search; contextual page help; the `B` shortcut.

Writes are offered to scheduling roles only. **This is presentation gating (PREF-08):** the unchanged scheduling API has no authentication or authorization. The source package has **no automated tests**, so none could be ported.
