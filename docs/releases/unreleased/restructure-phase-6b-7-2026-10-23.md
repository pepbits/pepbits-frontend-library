Daily timelines and source-bounded queues have no paging contract (case queries cap at 500); page-size controls are inapplicable. Native temporal inputs retain machine values. USD remains the source denomination. Source report/claim sections have no generic preview/export control, and no physical-device workflow is added. Existing bundled host fonts replace the source external stylesheet request.
