The unchanged API owns synthetic records, trusted actor/authorization, transaction/replay semantics and canonical catalogs. Each authenticated scope owns its cache, aborts obsolete reads and fences late replies. Commands retain replay keys across ambiguous failures. Recoverable validation errors preserve form input. No local token store, cross-branch cache or new durable-draft contract is introduced.

Effective theme/font/scales/radius, table presentation, page size, formatting, reduced motion and keyboard shortcuts remain host-controlled. Pharmacy appearance uses the central preference update path with live tenant locks. Server pharmacy currency is preserved; numeric/date/time presentation follows the user's effective format. Fixed thermal receipt dimensions are domain output. This source has no generic spreadsheet/designer/device workflow to duplicate; all phase 4c exports are already available.
