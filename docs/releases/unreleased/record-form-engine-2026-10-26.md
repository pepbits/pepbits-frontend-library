The patient list is unchanged. Layout setup is removed from healthcare, while the independent standalone app retains its designer. The compact band, hidden editor title and 8px top gap remain.

The [changed-file inventory](evidence/record-form-engine-2026-10-26/changed-files.txt) lists implementation, package/version, catalog, demo, test and documentation paths; retained evidence is listed separately by the links below.

Preferences → Forms exposes layout, shared density, columns, summary, validation timing and keep-unsaved, with user/tenant-policy parity. Shared density avoids a duplicate preference with conflicting semantics. Jenkins DEPLOY_TEST_SITE defaults to false; test-instance verification precedes an explicitly approved deployment.

## Data, errors and security

The frontend and independent mock backend normalize rail to scroll in stored overrides, imports, tenant defaults, locks and allowed lists. New defaults: formColumns 3, formShowSummary true, formValidateOn blur, formKeepUnsaved true; density remains shared comfortable. Existing records are unchanged. Healthcare keeps memory drafts only; disabling retention removes the saved memory draft without clearing open inputs. API failure/422/409 handling retains edits. The backend canonical catalogs cover en/ar/hi/ml. The new help snapshot preserves all historical evidence and native-review status of unchanged content; new prose remains pending review.
