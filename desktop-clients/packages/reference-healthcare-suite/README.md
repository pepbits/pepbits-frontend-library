# Healthcare Suite reference module

`@pepbits/reference-healthcare-suite` exports `ReferenceHealthcareSuiteModule({ path, host })`, `HEALTHCARE_SUITE_NAV`, `healthcareSuiteRoutes` and `resolveHealthcareSuiteRoute`. Import `@pepbits/reference-healthcare-suite/styles.css` before Tailwind `@source` declarations, and scan this package's `src` directory. The host owns the application header, navigation, authenticated actor, effective preferences, localization and transport.

The CarePoint source pages/components are adapted from `reference/frontend/healthcare-suite/healthcare-suite/frontend/src`. All 17 page templates and 23 navigation destinations are included, including 14 metadata-driven master workspaces with retained unsaved record tabs and independent list/new/record URLs. The original source remains untouched. Common controls, tables, cards, date/time inputs and dialogs render shared `@pepbits/ops-ui` primitives; the appointment slot board, clinical typeahead results, closable record tabs and notifications keep their specialized source layouts.

The module requests `/api` plus the original source endpoint through `ReferenceHost.fetch` or `request`. The host adds `/reference-modules/healthcare-suite`, product, module and branch scope plus authenticated credentials. Responses preserve the source's unwrapped contracts. Data, session and lookup rows come from the mock API backend; there are no browser seed datasets or fixture actors. `/session` must identify the actual host actor and return authorized active facilities and `canWrite`. Facility selections send `X-Reference-Facility`; the backend validates them. Client read-only controls supplement authoritative backend access checks.

Tables honor host density, stripes, sticky headers, wrapping, page size, result view and managed controls. Source tabs/pages map to `openRecordsInTabs` through the central preference update path. Patient previews use the five host preview placements, and billing/notification layouts use host preferences. Formatting, independent typography scales, radius, chosen font, reduced motion, shortcuts and direction follow the host. Export supports CSV; effective XLSX or forbidden formats disable the action with an explanation.

POST retries retain an operation key across recoverable failures in a mounted authenticated scope. Split collection uses an explicit stable key per payment line across the complete collection attempt. These keys are in-memory; they are not durable drafts or cross-tab transaction recovery. Typed values survive recoverable validation errors while the page stays mounted.

The canonical English copy/metadata inventory is `localization-inventory.en.json`, generated by `node scripts/generate-localization-inventory.mjs`; translated catalogs and generated fallbacks remain owned by the host repository. Package tests cover the actual host transport namespace, facility/scope isolation, source failures, replay keys, stale asynchronous reads, policy locks, formatting and source draft retention. Browser/production/native execution evidence belongs to the host's separately recorded verification.
