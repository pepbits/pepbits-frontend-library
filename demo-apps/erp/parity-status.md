# ERP parity ledger — phase 6c-6

All **114 catalogue destinations** are audited against the protected source templates/record components and CSS. Record/create/edit routes inherit their destination row. **No whole destination is certified as an exact pixel match.** This increment improves a coherent set of **35 destinations** (four bookings, sixteen profiles, four cases, three ERP2 tree records and eight reports), plus shared read-only field presentation. Remaining differences below are explicit, including unchanged families.

[Feature contract](../../docs/features/erp-demo.md), [release record](../../docs/releases/unreleased/restructure-phase-6c-6-2026-10-24.md), [read-only source audit](../../docs/releases/unreleased/evidence/restructure-phase-6c-6-2026-10-24/source-visual-audit.json). The audit identifies 84 original source files and each destination’s template/record source and geometry classes. Forced CI passes 6,097 tests (including 1,190 ERP tests), and shell Chromium passes 18 cases. The complete real-HTTP run passes 122 workflows, all 114 route/style/axe samples, 15 extra axe states and 27 selected record-state geometry comparisons, with zero violations or application/HTTP/console errors. Dimensions below are source-derived targets with selected values measured in the final browser receipt; the original desktop runtime was not rendered. This is not a screenshot-diff or native-executable certificate.

**Merged baseline reconciled:** 6c-5 already delivered report filters/sorting/subtotals, ledger/matrix controls and measured invoice pagination. Those are no longer pending parallel work. 6c-6 adds report columns and named snapshots, bringing coverage to **92 destinations** (84 worklists + eight reports). The source `{name,q,quick,filters}` view shape and hidden-column arrays remain, with additive named sort/column metadata. Explicit saves follow effective rememberFilters; columns follow columnLayoutScope. Failed column reads cannot overwrite the unread account layout.

**Preferences:** non-default effective presentation and tenant-lock differences are intentional. Field labels/values now use the source 12px/13.5px result-scaled stacked grid, with 16px horizontal/14px vertical gaps; edit inputs still use shared TemplateFields. Plain record chrome preserves effective rail/tabs/wizard navigation, density and reduced motion. Narrow containers keep context available below the form. Avatar accent initials use the effective text token for readable contrast; the source decorative accent is intentionally not used as small text.

**Draft boundary (out of scope for every editable destination):** source ERP forms do not persist drafts across routes/refresh. The browser unload warning remains; the protected API has no ERP form-draft contract. No business drafts enter browser storage or view-state. Support metadata has loading/retry/empty/version refresh; selected files remain explicitly local and unsaved.
